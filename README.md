# UWB Swarm
###### Status - Aktywny
Rój autonomicznych pojazdów na bazie podwozia miabotów, które mogą lokalizować się wzajemnie za pomocą modułów [UWB](https://en.wikipedia.org/wiki/Ultra-wideband).
Projekt realizowany jest w ramach grantu [IDUB](https://www.idub.agh.edu.pl/).

_Niech żyje rój!_

### Założenia/Cel
Wykonanie pojazdów mogących lokalizować się wzajemnie i wykonywać czynności autonomicznie.
